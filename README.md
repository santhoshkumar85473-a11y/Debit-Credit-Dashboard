Debit and Credit Dashboard

Project Overview
This project presents a Debit and Credit Dashboard developed using Tableau to help visualize and analyze financial transaction data.

 Tool Used
- Tableau

Project File
- `Debit Credit Dashboard1.twbx` — Packaged Tableau workbook.

Key Objectives
- Visualize debit and credit transactions.
- Present financial information in an interactive dashboard.
- Support easier financial data analysis and reporting.

 How to View
Download the `.twbx` file and open it using Tableau Desktop or a compatible Tableau application.
